## 確認・公開

index.html をブラウザーで開くと利用できます。GitHub Pagesでは、**既存ガイドとは別のリポジトリ**にこのフォルダー内のファイルを置き、index.htmlが公開元のルートに来るようにしてください。Settings → Pagesから新しいリポジトリの公開元を指定します。既存の tsumada-visit-guide リポジトリには上書きしないでください。すべてのCSS・JavaScriptは相対パスです。ビルドは不要です。

## 変更箇所

- js/config.js：予約URL・相談LINE・電話番号、LINE上の名称移行設定。
- js/menus.js：料金・時間・説明・注意事項。不明な料金や時間は項目自体を省略しています。
- js/flow.js：分岐。①と⑥はgetScreen/transitionを共用。⑥は首・肩からスタンダードへ進み、デスクワーク肩凝りを含むセット商品を選べません。
- js/app.js：画面描画、戻る、最初から。戻ると直前の状態に戻り、選び直すと後続の選択は置き換わります。
- css/style.css：スマートフォン優先のレイアウト。既存ガイドの配色・文字・ボタンの意匠を参照。
